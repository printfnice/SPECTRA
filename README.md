# SPECTRA Code

This repository is the code-only export of the `classification` project for the SPECTRA cell-cell communication study.

Included:
- `code/`: model, pipeline, processing, utility, testing, and visualization source code
- `scripts/`: helper scripts used during development

Excluded:
- manuscript files
- review notes and weekly reports
- datasets and intermediate artifacts
- trained checkpoints
- generated tables and figures
- local logs and other transient outputs

Recommended environment:
- Conda environment: `LIANA`

This GitHub export is intentionally limited to source code so that manuscript materials and local experimental artifacts remain private.
